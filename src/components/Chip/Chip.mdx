# Chip

We use **Chip** as a small interactive element for a single or multiple
selection. It works as a toggle — clicking or tapping switches it between
unselected and selected.

<Canvas of={ChipStories.Interactive} />

```tsx
<Chip size="md" active={selected} onClick={() => setSelected((v) => !v)}>
  Chip
</Chip>
```

## Anatomy

The bare minimum is the text only. The chip supports 3 sizes: **sm**
(`--size-7` (28px) — caption 13/20, `--size-2` (8px) padding), **md**
(`--size-8` (32px) — body 14/20, `--size-2_5` (10px) padding) and **lg**
(`--size-9` (36px) — body 14/20, `--size-3` (12px) padding). All three have
`--border-radius-1_5` (6px) corners.

<Canvas of={ChipStories.Sizes} />

Chip supports a **left slot**. The left slot supports an
<a href="/?path=/story/components-icon--default" target="_top">Icon</a>
and an avatar. The gap after the slot is `--size-1_5` (6px) in sm and
`--size-2` (8px) in md and lg.

Icon: size 14, and all parameters are editable. An icon with no color of its
own follows the label color, so it changes with the chip's state; an icon the
caller colored keeps that color.

<Canvas of={ChipStories.SlotLeftIcon} />

Avatar: the size is fixed — **xxs (16px)** in sm, **xs (20px)** in md and lg —
but any avatar is supported.

<Canvas of={ChipStories.SlotLeftAvatar} />

## Behavior

### Selected and unselected

Chip can be selected and unselected. Clicking or tapping on a chip switches
between these states. Both fill with `--gray-a2`; the 1px border changes —
`--gray-a7` when unselected, `--gray-12` when selected — and so does the text:
an unselected chip is `--text-subtle` at rest, a selected one is
`--text-strong`. `md` is the default size. `active` also sets `aria-pressed`,
so pass it on chips that work as toggles.

<Canvas of={ChipStories.ActiveInactive} />

### States

Each value has 5 states: default, focused (keyboard only), hovered, pressed and
disabled. **Inactive** hover keeps the fill and strengthens the border to
`--gray-a8`; press moves the fill to `--gray-a3` and keeps that border.
**Active** does not change on hover; press moves the fill to `--gray-a3` and
keeps the `--gray-12` border. **Focus** is the same on both values: a 2px
`--gray-12` stroke, with no gap. **Disabled** dims to 30% with the not-allowed
cursor.

An **inactive** chip also changes its text color: `--text-subtle` at rest and
when disabled, `--text-strong` on focus, hover and press. A left icon that has
no color of its own follows the same steps. An **active** chip is
`--text-strong` in every state.

### Loading

`isLoading` swaps the label for a skeleton bar and the left slot (if one is
set) for a `--gray-a3` circle — 14px for an icon, and the avatar's own size
(16px in sm, 20px in md and lg) for an avatar. The chip keeps the unselected
look, is not interactive, and shows the busy cursor.
