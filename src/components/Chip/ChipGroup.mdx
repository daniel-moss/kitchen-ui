# ChipGroup

We use **ChipGroup** to hold a row of
<a href="/?path=/docs/components-chip-chip--docs" target="_top">Chips</a>.
It places the chips, lets them wrap, and owns the group's validation state.

<FigmaLinks component="https://www.figma.com/design/ArSNpC1K8KiEvjCRHTzaLd/Design-System?node-id=29520-32450" />

```tsx
<ChipGroup>
  <Chip isSelected={selected === "a"} onClick={() => setSelected("a")}>
    Chip
  </Chip>
  <Chip isSelected={selected === "b"} onClick={() => setSelected("b")}>
    Chip
  </Chip>
</ChipGroup>
```

## Anatomy

The group is one row of Chips with `--size-2` (8px) between them. It has no
background, no border and no padding of its own — it takes the width of its
container.

<Canvas of={ChipGroupStories.Sizes} />

Chips of any size can go in a group. Keep **one size inside one group**.

## Behavior

### Wrapping

When the row runs out of width, the chips wrap onto the next line. The gap is
the same on both axes — `--size-2` (8px) between chips and between lines.

<Canvas of={ChipGroupStories.Wrapping} />

### Full width

`isFullWidth` flips the group to the stretch mode (like TabGroup's): one
non-wrapping row where the chips stop hugging and share the full width
equally, with the labels centered. Used for the weekday "Repeat on" row in
forms.

<Canvas of={ChipGroupStories.FullWidth} />

### Selection

**The group does not manage selection by itself.** Each Chip keeps its own
`isSelected` prop, so the consumer decides how many chips can be selected at
once.

Single-select — keep one value:

<Canvas of={ChipGroupStories.SingleSelect} />

Multi-select — keep a list of values:

<Canvas of={ChipGroupStories.MultiSelect} />

### Validation

`isValid={false}` turns every chip into its error look and shows the error
message `--size-1_5` (6px) below the chips, like the other group fields
(CheckboxGroup, RadioGroup). The message comes from `errorMessage`; inside an
<a href="/?path=/docs/components-input-input--docs" target="_top">Input</a>
with a string label it defaults to "Choose [Label]". The label and the help
text live on the Input wrapper — the group stays bare.
