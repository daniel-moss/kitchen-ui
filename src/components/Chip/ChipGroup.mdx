# ChipGroup

ChipGroup holds a row of
<a href="/?path=/docs/components-chip-chip--docs" target="_top">Chips</a>.
It places them, lets them wrap, and owns the group's validation — the chips
themselves only know whether they are selected. It has no background, no border
and no padding of its own.

## Anatomy

A row of Chips, and below it the error message when the group is invalid. The
group takes the width of its container.

A group holds one kind of chip. Keep one size and one orientation inside a
group.

## Wrapping

When the row runs out of width the chips wrap onto the next line. The gap is
`--size-2` (8px) between chips and between lines.

<Canvas of={ChipGroupStories.Wrapping} />

## Full width

`isFullWidth` flips the group to the stretch mode. The chips stop hugging their
labels and share the row equally, each label centered, and the row no longer
wraps.

`isFullWidth = false`

<Canvas of={ChipGroupStories.FullWidthOff} />

`isFullWidth = true`

<Canvas of={ChipGroupStories.FullWidth} />

This is the mode for a switcher: a small, fixed set of options that should read
as one control.

## Selection

The group places the chips. It does not track which one is on — each chip
carries its own `isSelected` and the consumer decides what happens on a click.

That makes two patterns. **Pick one:** clicking a chip selects it and clears
the others, and one chip is always selected. **Pick many:** each chip toggles
on its own, and none, some or all can be selected at once.

`selectionMode` says which one this group is, so the chips announce themselves
correctly. **"multiple"** (the default) makes each chip a toggle button with
`aria-pressed`, and Tab stops on every one of them. **"single"** makes the row
a radio group: each chip is `role="radio"` with `aria-checked`, Tab stops on
the row once — at the selected chip, or the first one when none is selected —
and the arrow keys move between chips, clicking as they go so the selection
follows the focus.

## Validation

`isValid={false}` turns every chip in the group into its error look and shows
the message `--size-1_5` (6px) below the row. One chip cannot be invalid on its
own — the group is the unit that fails.

<Canvas of={ChipGroupStories.Validation} />

The message is an error
<a href="/?path=/docs/components-inputhelptext--docs" target="_top">InputHelpText</a>.
Inside an
<a href="/?path=/docs/components-input-input--docs" target="_top">Input</a>
with a string label it defaults to "Choose [Label]". The label and the help
text belong to the Input wrapper; the group itself stays bare.

## Usage

A ChipGroup sits inside the form, panel or menu that owns the choice.

| Component | Where |
| --- | --- |
| Input | the wrapper that owns the label and the help text |
| SelectListHeader | the chip row above the search |
| "View" menu | view switcher, Timeline settings, Cards attributes |
| Duration presets | new job and new service forms |
| Filters | the timeframe and condition choices inside a filter's editor |
