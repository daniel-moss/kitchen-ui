# ListItem

ListItem is a row that represents an object — a location, a client, a file, a
contact. It holds the text, an optional avatar, up to three elements on the
right, and one full-width element at the bottom. The row can be static,
clickable, draggable or an accordion.

## Anatomy

Contains an optional grip or caret, the body, and an optional element at the
bottom. The body is
<a href="/?path=/docs/components-itemtext-itemtext--docs" target="_top">ItemText</a>
with an optional avatar before it. Everything is vertically centered, and the
row grows when the text wraps.

<Canvas of={ListItemStories.Anatomy} />

Radius is `--border-radius-1_5` (6px). The grip and the caret sit `--size-3`
(12px) from the body.

<Canvas of={ListItemStories.AnatomyGripCaret} />

## Size

Two sizes. **Default** is 60px — `--size-2_5` (10px) padding over a 40px body.
**Compact** is 40px: no vertical padding, so a 32px IconButton still fits.

<Canvas of={ListItemStories.Sizes} />

Compact is for **one line of text**. Do not use it with a caption, and do not
use an avatar in the left slot — both fill the row and leave nothing to breathe.
It is the size for rows whose value or control sits on the right: the View
menu's column rows, a settings toggle.

<Canvas of={ListItemStories.CompactControls} />

That rule is written down rather than type-enforced, because `variant` and
`avatar` reach ListItem through the text and content props.

## Content

The left slot takes an
<a href="/?path=/story/components-avatar--playground" target="_top">Avatar</a>
at xl (36px), `--size-3` (12px) before the text.

<Canvas of={ListItemStories.LeftSlot} />

The text is
<a href="/?path=/docs/components-itemtext-itemtext--docs" target="_top">ItemText</a>
— the same component SelectListItem, MenuItem and DisplayModule use. Its
layouts, colors, slots and truncation rules are documented there.

<Canvas of={ListItemStories.TextVariants} />

Text that wraps grows the row, and everything else centers against it.

<Canvas of={ListItemStories.MultiLine} />

## Right elements

Up to three elements on the right, `--size-2` (8px) apart and `--size-3` (12px)
from the text.

<Canvas of={ListItemStories.RightSlots} />

Slot 1 sits at the row's edge. Adding a second slot inserts it to the left, so
the first element never moves.

<Canvas of={ListItemStories.SlotOrder} />

Each slot takes an Avatar, an AvatarGroup, a Button, an IconButton, an Input, an
<a href="/?path=/docs/components-itemtext-itemvalue--docs" target="_top">ItemValue</a>,
an open chevron, an open-in-new-tab arrow, a ProgressRing, a TabGroup or a
Toggle. The Input covers text and date fields — a value the row picks belongs in
an ItemValue instead.

<Canvas of={ListItemStories.SlotInstances} />

`open` and `openInNewTab` are the row's own affordance — `angle-right` when the
row opens the object, `arrow-up-right` when it opens in a separate tab. A row
never carries both. Use `ListItemSlotIcon` for either.

<Canvas of={ListItemStories.SlotAffordance} />

ItemValue is the row's current value when tapping the row changes it in place.
When the value is only read here, use a tag in ItemText's right block instead.

<Canvas of={ListItemStories.SlotItemValue} />

## Bottom element

One element below the body, stretched to the full width, `--size-2` (8px) under
it. It takes a Button, an Input or a TabGroup. The Input covers text, select and
date fields.

<Canvas of={ListItemStories.BottomInstances} />

The bottom element is a mobile adaptation. A row that has one is static — it
cannot be clickable, draggable or an accordion, and there is no compact version
of it. TypeScript enforces this, so `slotBottom` only type-checks on a plain
row.

## Dragging

A draggable row shows a grip on the left (`isDraggable`). While dragging
(`isDragging`), the grip becomes `arrows-up-down` and the row lifts into a card
— third-level surface, a 1px `--gray-12` border and a shadow.

<Canvas of={ListItemStories.DragStates} />

The whole row is the drag trigger, not only the grip. **ListItem does not
reorder anything by itself** — the list container does:
<a href="/?path=/docs/components-itemgroup--docs" target="_top">ItemGroup</a>
wires the gesture with `onReorder`.

## Interactivity

A clickable row (`isClickable` + `onClick`) responds to hover, press and focus.
Hover fills `--gray-a3`, press `--gray-a4`, focus draws a 2px ring with a 2px
gap, and disabled dims the row to 30%.

`isClickable = true`

<Canvas of={ListItemStories.ClickableStates} />

`isClickable = true, isDraggable = true`

<Canvas of={ListItemStories.ClickableDraggableStates} />

State applies to clickable, draggable and accordion rows only. A static row has
one state.

<Canvas of={ListItemStories.StaticNoStates} />

Clicks inside the right slot and the bottom element do not trigger the row, as
long as they land on a real control. Static elements such as the chevron or an
avatar belong to the row and do trigger it.

<Canvas of={ListItemStories.SlotClicks} />

## Accordion

An accordion row (`isAccordion` + `children`) is a header that opens a body
below a
<a href="/?path=/docs/components-divider--docs" target="_top">Divider</a>
that runs the full width of the row. When open, the whole row takes a
`--gray-a2` background.

<Canvas of={ListItemStories.AccordionSizes} />

The body is a slot — there is no restriction on what goes in. It has
`--size-3` (12px) padding on every side, and the row grows to whatever height
the content needs.

<Canvas of={ListItemStories.AccordionBody} />

The header keeps the clickable states. `disabled` dims only the header, so an
open body stays readable.

`isAccordion = true, open = false`

<Canvas of={ListItemStories.AccordionStates} />

`isAccordion = true, open = true`

<Canvas of={ListItemStories.AccordionOpenStates} />

An accordion cannot be draggable, and it has no bottom element.

## Loading

A loading row (`isLoading`) shows a bar for each line of text and a placeholder
for the avatar. Two sizes, and nothing else: the grip, the caret, the right
elements and the bottom element are all hidden while loading.

<Canvas of={ListItemStories.Loading} />

The row keeps its height, so nothing jumps when the content arrives. Default is
two bars with an avatar; compact is one bar without — the same rule the size
section describes.

<Canvas of={ListItemStories.LoadingList} />

The hidden elements are controls, not content. There is no order to drag a row
into yet and nothing to expand behind it, so showing a grip or a caret would
offer an action that cannot answer. Placeholders stand in for content; controls
wait.

<Canvas of={ListItemStories.LoadingHidesControls} />

The avatar is a placeholder only when the object type is unknown. In a list of
one kind — clients, jobs, invoices — use that object's generic avatar instead,
because the type is known before the data arrives.

<Canvas of={ListItemStories.LoadingKnownObjectType} />

The avatar is optional and the text layout is free. Leave the left slot out for
a row without one, and set the text block to whichever layout the loaded row
uses.

<Canvas of={ListItemStories.LoadingLayouts} />

`isLoading` combines with every other prop on purpose — a list renders the same
row and drives the flag from its query.
