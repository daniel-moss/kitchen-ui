# ProgressRing

We use **ProgressRing** to show progress as a ring that fills clockwise. It has
one fixed 16×16 size, for tight places where a full-width bar does not fit.

## Anatomy

Two layers: the **background** ring and the **progress ring** over it.

Height and width are fixed — `--size-4` (16px) square. Both layers are the same
circle: radius 7 with a 2px stroke, so the ring's outer edge sits exactly on the
box edge. The background is `--gray-a6` and is constant; only the progress ring
takes a color, and its ends are rounded.

<Canvas of={ProgressRingStories.Anatomy} />

## Behavior

The progress ring starts at 12 o'clock and grows clockwise until it closes the
full circle, which equals 100%. At 0% only the background ring is drawn.

`value` accepts 0–100 and is clamped to that range.

## Colors

The progress indicator supports any color — pass `color` as a CSS color, normally
a token (`var(--jade-9)`). The background ring keeps its constant color.

<Canvas of={ProgressRingStories.Colors} />

## Loading

The loading state (`isLoading`) uses the empty ring with the standard pulsing
animation — the same pulse as
<a href="/?path=/story/components-avatar--playground" target="_top">Avatar</a>
and Skeleton. The progress ring is not drawn while loading.
