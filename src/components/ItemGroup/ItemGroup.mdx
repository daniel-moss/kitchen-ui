# ItemGroup

ItemGroup is a set of related items under one label — the jobs on a client, the
files in a folder, a block of settings. It holds an optional header, the items
as a list of ListItems or a wrap of Cards, an optional button that reveals the
rest, and an optional divider that separates it from the group below. The header
can collapse the whole group.

</ItemGroup>

## Anatomy

Contains an optional header, the items, an optional button below them, and an
optional divider at the very bottom. The group has no background of its own — it
is transparent, and the divider does the separating.

<Canvas of={ItemGroupStories.Anatomy} />

The header has `--size-3` (12px) margins. The items are inset `--size-1` (4px)
in list view and `--size-4` (16px) in cards view. The button has 16px side
margins and `--size-2_5` (10px) below it. The bottom divider is inset 16px on
each side.

<Canvas of={ItemGroupStories.WithHeader} />

Three rules decide which parts can be combined. All three are enforced by the
types, not only written down.

| Rule | Why |
| --- | --- |
| Header | needed for the accordion |
| Accordion | never truncated — collapsing is what it does |
| Separated | never truncated |

## Header

The header is a
<a href="/?path=/docs/components-grouplabel--docs" target="_top">GroupLabel</a>.
Its label, counter, caption, left slot, action and states are set on it — the
group takes the whole element as `label`.

<Canvas of={ItemGroupStories.HeaderContent} />

We label a group only when there is more than one. A single group carries no
header.

<Canvas of={ItemGroupStories.DefaultGroup} />

## Items

The items sit in a slot. List view takes
<a href="/?path=/docs/components-listitem-listitem--docs" target="_top">ListItem</a>s,
cards view takes Cards. In Figma each view has its own slot, so a group can hold
both and switching the view keeps them; in code the items are `children` and the
caller swaps them with `view`.

<Canvas of={ItemGroupStories.ItemsViews} />

List view stacks ListItems with no gap between them.

<Canvas of={ItemGroupStories.DefaultGroup} />

Cards view wraps the Cards at 12px gaps. Each card flexes between 106 and 184px
wide. When several groups sit in one module, their cards share one width even if
the groups hold different numbers of cards — set `cardCountBasis` to the largest
count among them.

<Canvas of={ItemGroupStories.Cards} />

**Separated.** A group can put a divider between every two items — we use it in
Settings. The dividers are horizontal, low contrast, 4px above and below and
12px on the sides. A separated group is never truncated.

<Canvas of={ItemGroupStories.SeparatedItems} />

## Truncation

Truncation shows the first few items and a full-width button that reveals the
rest. The button is a lg ghost
<a href="/?path=/story/components-button--playground" target="_top">Button</a>
with `angles-up-down`, and it names how many items are hidden.

<Canvas of={ItemGroupStories.Truncation} />

Expanding is two-way. Once the group is open the button becomes "Show less" with
`regular-collapse`, and the group collapses back to the first few items.

## Accordion

The header becomes a toggle that collapses the group (`isAccordion`). The caret
and the hover, press, focus and disabled states all belong to GroupLabel — set
them there.

<Canvas of={ItemGroupStories.Accordion} />

A collapsed group draws the header alone, with even 12px padding. The items stay
mounted while the group is closed, so opening it brings them back.

An accordion is never truncated. Collapsing is what the accordion does.

## Stacking

Groups stack with no gap between them. The bottom divider does the separation,
so every group except the last one carries it.

<Canvas of={ItemGroupStories.StackedGroups} />

The divider is inset 16px on each side.

## Reordering

Items can be reordered inside a group by dragging (`onReorder`). The ListItem
shows a grip, the dragged row lifts into a card, and an empty slot marks where
it will drop. A long press anywhere on the row starts the drag too.

<Canvas of={ItemGroupStories.Dragging} />

In cards view a long press starts the drag and the grid reflows in two
dimensions to open the drop slot.

<Canvas of={ItemGroupStories.Cards} />

**ItemGroup reports the move — the screen reorders the items.** `onReorder` is
called with the old and new index; the group renders `children` exactly as
given. The rows need `isDraggable`.
