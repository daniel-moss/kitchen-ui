# FilterChip

We use **FilterChip** to show one applied filter as a 'property – condition –
value' expression. Users can change the condition and the value in place, or
remove the filter.

<Canvas of={FilterChipStories.Hero} />

```tsx
<FilterChip
  slotLeft={<Icon icon="diamonds-4" size={14} />}
  property="Property"
  condition="is"
  value="Value"
  onConditionClick={openConditionList}
  onValueClick={openValueList}
  onRemove={() => removeFilter(filter)}
/>
```

## Anatomy

Supports 2 variants: mobile and desktop. They are identical from a
functionality perspective but slightly differ visually.

### Chip container

#### Desktop

Fixed height — `--size-8` (32px). Consists of "property", "condition", "value"
and "remove" boxes separated by a
<a href="/?path=/docs/components-divider--docs" target="_top">Divider</a>
component (vertical, medium contrast). Boxes fill the height. The chip hugs
the content. "property", "condition" and "value" boxes hug the content as
well. The "remove" box has a fixed width — `--size-8` (32px). The chip
surface is `--surface-interactive-default` with a `--border-radius-1_5` (6px)
radius and the `--box-shadow-xs-down` shadow.

<Canvas of={FilterChipStories.ChipContainerDesktop} />

#### Mobile

Fixed height — `--size-9` (36px). Consists of "property", "condition", "value"
and "remove" boxes separated by a
<a href="/?path=/docs/components-divider--docs" target="_top">Divider</a>
component (vertical, medium contrast). Boxes fill the height. The chip fills
the width. "property" and "condition" boxes hug the content. "value" box
fills the width. The "remove" box has a fixed width — `--size-9` (36px). The
surface is the same as on desktop.

<Canvas of={FilterChipStories.ChipContainerMobile} />

### Content box

The only difference between the desktop and the mobile versions is the left
and right padding — `--size-2_5` (10px) on desktop, `--size-3` (12px) on
mobile.

<Canvas of={FilterChipStories.ContentBoxPaddings} />

The bare minimum the box can contain is text only. The text is
`body-400-compact` (Regular 14/20), `--text-strong`.

<Canvas of={FilterChipStories.ContentBoxText} />

The box supports a left slot. The left slot supports an
<a href="/?path=/story/components-icon--playground" target="_top">Icon</a>
and an
<a href="/?path=/story/components-avatar--playground" target="_top">Avatar</a>.
The slot sits `--size-2` (8px) before the text.

- Icon: all parameters are flexible; the default is 14px, regular, `--gray-12`;
- Avatar: the size is fixed — **xs (20px)**. All avatars are supported.

<Canvas of={FilterChipStories.ContentBoxSlot} />

### "Remove" box

The only difference between the desktop and the mobile versions is the width —
`--size-8` (32px) on desktop, `--size-9` (36px) on mobile. The icon is
identical — `xmark`, 14px, regular, `--gray-a9`.

<Canvas of={FilterChipStories.RemoveBox} />

## Behavior

### Content box

"isClickable" property controls interactivity

In code, a box is interactive when its click handler is set
(`onConditionClick` / `onValueClick`) — without a handler the box renders
non-interactive. (The example below is live — hover the clickable box.)

<Canvas of={FilterChipStories.IsClickable} />

Interaction states:

- Hovered: `--gray-a2` fill;
- Pressed: `--gray-a3` fill;
- Focused: `--gray-a2` fill and a 2px `--gray-12` stroke (an inset stroke — it
  does not change the box size);
- Disabled: 30% opacity and a not-allowed cursor.

<Canvas of={FilterChipStories.InteractionStates} />

The content box on the desktop has a max width — 240px. The text truncates if
it does not fit. If truncated, we show a tooltip with the full value — the
whole box is the tooltip's trigger. (The example below is live — hover the
box.)

<Canvas of={FilterChipStories.MaxWidth} />

#### "Property" box

Usually consists of an icon and text. Non-interactive.

<Canvas of={FilterChipStories.PropertyBox} />

#### "Condition" box

Usually consists of text only. It is usually clickable but in fixed filters it
is not. Usually triggers a
<a href="/?path=/story/components-selectlist-selectlist--playground" target="_top">SelectList</a>
with the list of condition options.

<Canvas of={FilterChipStories.ConditionBox} />

#### "Value" box

It is usually clickable but in fixed filters with one value it is not.
Usually triggers either a
<a href="/?path=/story/components-selectlist-selectlist--playground" target="_top">SelectList</a>
with the list of value options or a
<a href="/?path=/story/components-dialog--playground" target="_top">Dialog</a>.

<Canvas of={FilterChipStories.ValueBox} />

#### "Remove" box

Is clickable. Removes the filter chip from the list.

<Canvas of={FilterChipStories.RemoveStates} />

Hovering it triggers a tooltip. (The example below is live — hover the box.)

<Canvas of={FilterChipStories.RemoveTooltip} />

### Fixed filter

"isFixed" property controls whether the chip is adjustable. The fixed chip
doesn't have the "remove" box.

<Canvas of={FilterChipStories.IsFixed} />

The "condition" box is not clickable.

<Canvas of={FilterChipStories.FixedCondition} />

If the "value" box contains one value only, it is not clickable.

<Canvas of={FilterChipStories.FixedValueSingle} />

If the "value" box contains multiple selected value options, it opens a
<a href="/?path=/story/components-selectlist-selectlist--playground" target="_top">SelectList</a>
with a list of all selected options in `readOnly` state.
