# CheckboxItem

We use **CheckboxItem** when there are up to 4 options and multiple selection
is required. The whole item is one control — clicking anywhere on it toggles
the checkbox.

<Canvas of={CheckboxItemStories.Interactive} />

```tsx
<CheckboxItem
  variant="card"
  label="Send invoice reminders"
  caption="E-mail the client when an invoice is overdue"
  checked={reminders}
  onChange={(e) => setReminders(e.target.checked)}
/>
```

## Inline

The inline variant does not have a background. It consists of
<a href="/?path=/docs/components-checkbox-checkbox--docs" target="_top">Checkbox</a>
and text. Elements are top-aligned — the checkbox has offsets (a 2px top
offset, `--size-2` (8px) before the text) which keep the elements aligned when
there are multiple lines of text. The label is Medium strong; the caption is
Regular subtle, `--size-0_5` (2px) below.

<Canvas of={CheckboxItemStories.Inline} />

The inline variant supports a caption.

<Canvas of={CheckboxItemStories.InlineCaption} />

CheckboxItem supports an icon on the left. Elements are top-aligned — the
icon has offsets (a 16px box with a 2px top offset and `--size-2` (8px) on
the right) to align it perfectly.

## Card

The card variant has a background; the checkbox sits on the right. It
consists of
<a href="/?path=/docs/components-checkbox-checkbox--docs" target="_top">Checkbox</a>
and text. Elements are top-aligned — the checkbox has offsets which keep the
elements aligned when there are multiple lines of text. The card: `--size-3`
`--size-4` (12px 16px) padding, `--size-4` (16px) gap, `--border-radius-1_5`
(6px) corners. A checked card gets the dark stroke, the raised surface and
the elevation shadow.

An active (checked) card has 2 variants: with and without a **content
container**. The content container is used when we need to show additional
content related to the selected option. It can contain any type of content —
the same logic as for
<a href="/?path=/story/components-displaymodule--playground" target="_top">DisplayModule</a>.
The container is separated by a divider and has `--size-4` (16px) padding.
(Both cards below are live — uncheck one to hide its container.)
