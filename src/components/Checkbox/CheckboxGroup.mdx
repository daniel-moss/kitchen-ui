# CheckboxGroup

We use **CheckboxGroup** for grouping checkbox items when there are up to 4
options and multiple selection is allowed. The group is bare — its label and
help text come from the
<a href="/?path=/docs/components-input-input--docs" target="_top">Input</a>
wrapper.

<Canvas of={CheckboxGroupStories.Interactive} />

```tsx
<Input label="Type">
  <CheckboxGroup orientation="horizontal" isValid={isValid}>
    <CheckboxItem label="Repair" />
    <CheckboxItem label="Maintenance" />
    <CheckboxItem label="Install" />
  </CheckboxGroup>
</Input>
```

## Anatomy

Items in the checkbox group might be aligned **vertically** or
**horizontally**. The checkbox group supports the **card**
<a href="/?path=/docs/components-checkbox-checkboxitem--docs" target="_top">CheckboxItem</a>
variant only — the group forces it on every item. The items sit `--size-2`
(8px) apart; horizontal items share the width equally.

<Canvas of={CheckboxGroupStories.Orientation} />

## Behavior

If selection is required and the user leaves the checkbox group without a
selection, we show the error state after validation: every item turns error
and one shared message shows `--size-1_5` (6px) below. The default message is
**“Choose [Label]”** — derived automatically from the Input label
(`errorMessage` overrides it).
