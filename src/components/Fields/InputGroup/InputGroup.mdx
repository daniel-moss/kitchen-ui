# InputGroup

We use **InputGroup** for combining fields that are considered **one piece of
data** and share the same error message. The group is bare — its label and
help text come from the
<a href="/?path=/docs/components-input-input--docs" target="_top">Input</a>
wrapper.

<Canvas of={InputGroupStories.Playground} />

```tsx
<Input label="Date & time">
  <InputGroup isValid={isValid}>
    <DateField defaultValue={date} />
    <SelectField value={repeat} onClick={openRepeatList} />
  </InputGroup>
</Input>
```

## “Missing value” message

The message starts with the verb **“Provide”**, followed by the input label,
which starts with an uppercase letter. No period in the end. When the group is
**empty**, the message is derived automatically from the Input label — below,
the label “Amount” becomes “Provide Amount”. A **filled** group with a wrong
value gets its own message through `errorMessage` (the “Error message”
examples above).
