# SelectField

We use **SelectField** for selecting one or multiple options.

<Canvas of={SelectFieldStories.Basic} />

```tsx
<Input label="Location">
  <SelectField value={location?.name} onClick={openLocationList} />
</Input>
```

## Anatomy

### Single-select

Doesn't support a placeholder. Any informative text is shown either as a
hint, or as help text on the
<a href="/?path=/docs/components-input-input--docs" target="_top">Input</a>
wrapper.

<Canvas of={SelectFieldStories.Empty} />

Filled:

<Canvas of={SelectFieldStories.FilledOut} />

Supports a left slot with an icon or an avatar (`slotLeft`):

- Avatar: any type of avatar, but size matters — xs (20px)
- Icon: size and color may vary

<Canvas of={SelectFieldStories.LeftSlot} />

Supports a suffix (`suffix` — subtle text after the value):

<Canvas of={SelectFieldStories.WithSuffix} />

### Multi-select

Contains a counter when filled (`count` > 0). The counter shows how many
options are selected:

<Canvas of={SelectFieldStories.Basic} />

Supports left and right slots:

### Multi-select

When 1 option is selected, the name of the selected option is shown in the
field. If more than 1 is selected, the field shows "Options selected" by
default. If the designs specify the exact copy for multiple options
selected, we use it instead (`multiSelectLabel`) — e.g. "locations",
"clients", etc.:

<Canvas of={SelectFieldStories.MultiSelectCopy} />

Clicking the "Clear all" button clears the field. The × carries a
"Clear all" tooltip on hover, and its touch area extends 4px beyond the
visible circle on all sides:

<Canvas of={SelectFieldStories.ClearAll} />

which starts with an uppercase letter. No period in the end. It derives from
the Input wrapper's label automatically — the example below passes no
