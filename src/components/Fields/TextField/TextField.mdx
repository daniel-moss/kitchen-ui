The message starts with the verb **"Enter"** followed by the input label,
which starts with an uppercase letter. No period in the end. It derives from

### Mobile keyboard

The `keyboard` prop picks the mobile on-screen keyboard (it maps to the
native `type`/`inputMode` attributes — open this page on a phone to feel the
difference):

- By default, we use the `text` keyboard variant
- If the input handles email-format data, the `email` keyboard must be used
- If the input handles URL-format data, the `url` keyboard must be used
- If the input handles phone-format data, the `tel` keyboard must be used
  (the math-modifiers button is not shown)
- If the input handles phone extension data, the `numeric` keyboard must be
  used
