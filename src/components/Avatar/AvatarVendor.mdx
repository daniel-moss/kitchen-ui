An avatar with vendor-based parameters. It is based on the
<a href="/?path=/story/components-avatar--playground" target="_top">Avatar</a>
component — a square object avatar — so the sizes, corners and loading surface
all come from Avatar.

## Content

Supports an image and an icon (`content`). If the logotype is uploaded, the
avatar shows the logo (`content="image"` with `imageSrc`). Otherwise, it shows a
generic icon — the solid `store` glyph, the design system's `vendor` semantic
icon. Default `icon`. Without an `imageSrc`, the image content falls back to the
object placeholder.

Every size from Avatar is supported: `xxs` (16px), `xs` (20px), `sm` (24px),
`md` (28px), `lg` (32px) and `xl` (36px). Default `md`.

## Add-ons

The add-on (`addOn`) sits in the bottom-right corner and cuts a notch out of the
avatar, so a ring of the surface behind shows around it. Default `none`.

### Active

Vendor's status is "active". The add-on is a `--jade-a9` status dot.

### Preferred

The vendor is marked as "Preferred vendor". The add-on is the solid `crown`
icon in `--amber-a10` — the same crown
<a href="/?path=/docs/components-avatar-avataruser--docs" target="_top">AvatarUser</a>
uses for a primary contact.

## Loading

On loading state, we don't know the vendor's status or whether it has a logo.
But we do know that the avatar is going to be a vendor avatar. So, use the
generic variant without status: `content="icon"` and `addOn="none"`.
AvatarVendor has no `isLoading` prop of its own.
